## How to read this log

**The Brand Standards hub's Decision log wins on logo, color and type.** It also wins on voice, rights and every other brand rule. This log covers how an issue is designed and produced. If a line here ever disagrees with the hub, follow the hub and add the conflict to 13 Open Questions for Heather.

Rules for reading a row:

1. **Newest Heather decision wins.** When two rows disagree, the newer row that says "Yes" in the Heather column wins.
2. **"Yes" means Heather made the call herself,** in her own words or by approving the document that holds the rule. "Via hub" means the rule sits in the hub, which only Heather approves.
3. **"No" means the rule is a team standard, a spec rule or an outside fact** (for example, a KDP rule). It stands until Heather changes it, but she has not ruled on it herself.
4. **Interim rules are not decisions.** Where the set says "Follow X until Heather decides," the question is in 13 Open Questions for Heather, not here.
5. **Hub rows** copy the hub's own Decision log lines that this set relies on. Hub lines about video and scripts only (the standing intro, the host split, chapter titles, what hosts say on screen) are left out. Read them in the hub.

Docs are named by number in the "Applied in" column. The full titles are in the Related line above.

## How to add a decision

This follows 01 Issue Design Process: From Brief to Print-Ready Files, section 9.

1. **Get Heather's yes in writing.** A decision enters this log only after Heather approves it, or after it appears in the hub's Decision log. An agent's or vendor's suggestion is not a decision.
2. **Check the hub first.** If the decision is about logo, color, type, voice or rights, it belongs in the hub's Decision log. Ask the hub owner to add it there, then copy the line here only if this set relies on it.
3. **Add one row** in the right section. Use the next free ID (never reuse an ID, even for a row that is later replaced). Fill every column: date (YYYY-MM-DD), the decision as a rule someone can check, the source by title and date, whether it is Heather's own call, and which docs apply it.
4. **Mark what it replaces.** If it overrides an earlier row, write "Replaced by D-0NN on <date>" at the end of the old row's Decision cell. Leave the old row in place.
5. **Close the open question.** If it answers a question in 13 Open Questions for Heather, move that question to the "Answered" list there with the new decision ID.
6. **Fix the docs.** Each doc owner updates the docs in "Applied in," bumps their version (whole number if a rule changed, decimal for wording), and notes the decision ID in the change.
7. **Tell anyone mid-issue.** An issue past Stage 2 may finish on the old rule unless Heather says otherwise (01, section 9). Record which rule the issue used in its Release Note.

Only the process owner (the Documentation Specialist for Process and Governance) edits this log. Agents never write "Heather's own call: Yes" without her words or an approved document to point to.
